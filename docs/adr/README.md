# Architecture Decision Records

Each ADR below expands on the one-line entries carried in
`docs/IMPLEMENTATION_STATUS.md`'s "Architecture Decisions" section, with
real context/consequences grounded in the actual implementation rather
than the decision alone. Where a decision has only been partially
realized, that's stated in its own "Current state" section — an ADR
records what was decided and why, not a claim that it's 100% built out.
